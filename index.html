Minify

The source is tokenized with a real Lua lexer (long strings, long comments, hex/float numerics, escape sequences) and reassembled without whitespace or comments.

Encrypt

The minified payload is XOR-encrypted with a fresh 16-byte key generated per build via crypto.getRandomValues, then serialized as \ddd byte escapes.

VM loader

The payload ships inside a setmetatable({...}) header matching Luraph v15's field shape (oO / nO / Pt / [42] / [91] / [101] / [105] / [123]). At runtime the loader decrypts and loadstring's it.

Educational tool. Output runs on Lua 5.1+ / Luau (uses loadstring or load). This is not the real Luraph service — it mimics the output style of Luraph v15 for learning and personal use.
